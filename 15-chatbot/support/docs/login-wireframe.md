# 로그인 화면 와이어프레임

## 화면 개요

캠퍼스 고객센터 AI 챗봇을 사용하기 위한 로그인 화면이다.

모바일 앱 화면처럼 세로로 긴 단일 화면으로 구성한다.

---

## 화면 구조

```text
┌──────────────────────────────┐
│                              │
│                              │
│                              │
│        캠퍼스 고객센터        │
│                              │
│   ┌──────────────────────┐   │
│   │ 사용자 이름           │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │ 패스워드              │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │        로그인         │   │
│   └──────────────────────┘   │
│                              │
│                              │
└──────────────────────────────┘
```

---

## UI 구성 요소

### 1. 화면 제목

```text
캠퍼스 고객센터
```

* 화면 중앙에 크게 표시한다.
* 서비스의 대표 제목 역할을 한다.

### 2. 사용자 이름 입력 필드

```text
사용자 이름
```

* 사용자의 로그인 ID를 입력받는다.
* placeholder 예시:

```text
사용자 이름을 입력하세요
```

### 3. 패스워드 입력 필드

```text
패스워드
```

* 사용자의 비밀번호를 입력받는다.
* 입력 값은 화면에 노출되지 않도록 password 타입으로 처리한다.
* placeholder 예시:

```text
패스워드를 입력하세요
```

### 4. 로그인 버튼

```text
로그인
```

* 사용자 이름과 패스워드를 사용해 로그인 요청을 수행한다.
* 로그인 성공 시 채팅 화면으로 이동한다.
* 로그인 실패 시 오류 메시지를 표시한다.

---

## 화면 동작

1. 사용자가 사용자 이름을 입력한다.
2. 사용자가 패스워드를 입력한다.
3. 로그인 버튼을 클릭한다.
4. 인증 성공 시 채팅 화면으로 이동한다.
5. 인증 실패 시 로그인 화면에 오류 메시지를 표시한다.

---

## 디자인 가이드

* 모바일 앱처럼 세로로 긴 화면을 기준으로 설계한다.
* 전체 레이아웃은 중앙 정렬한다.
* 입력 필드와 버튼은 손가락으로 누르기 편한 크기로 구성한다.
* 로그인 버튼은 화면에서 가장 눈에 잘 띄도록 강조한다.
