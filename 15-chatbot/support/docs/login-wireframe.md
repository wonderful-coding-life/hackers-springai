# 로그인 화면 와이어프레임

## 화면 개요

캠퍼스 고객센터 AI 챗봇의 로그인 화면이다.

모바일 앱 형태의 단일 화면으로 구성한다.

---

## 화면 구조

```text
┌──────────────────────────────┐
│                              │
│        캠퍼스 고객센터        │
│                              │
│   ┌──────────────────────┐   │
│   │ 사용자 이름           │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │ 패스워드              │   │
│   └──────────────────────┘   │
│                              │
│   ┌──────────────────────┐   │
│   │        로그인         │   │
│   └──────────────────────┘   │
│                              │
└──────────────────────────────┘
```

---

## UI 구성 요소

### 1. 화면 제목

```text
캠퍼스 고객센터
```

### 2. 사용자 이름 입력 필드

```text
사용자 이름
```

placeholder 예시

```text
사용자 이름을 입력하세요
```

### 3. 패스워드 입력 필드

```text
패스워드
```

placeholder 예시

```text
패스워드를 입력하세요
```

### 4. 로그인 버튼

```text
로그인
```
