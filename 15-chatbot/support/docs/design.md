# 캠퍼스 고객센터 디자인 가이드

## 목표

캠퍼스 고객센터 AI 챗봇 화면을 실제 서비스처럼 깔끔하고 신뢰감 있게 구현한다.

전체 디자인은 다음 느낌을 목표로 한다.

* 모바일 앱 같은 화면
* 친근한 고객센터 상담 화면
* 읽기 쉬운 채팅 UI
* 단순하지만 완성도 있는 스타일
* 실제 서비스처럼 자연스러운 사용자 경험

## 화면 레이아웃

* 화면은 모바일 앱처럼 세로로 긴 형태를 기준으로 만든다.
* 데스크톱 브라우저에서는 모바일 앱 화면이 가운데 배치된 것처럼 보이게 한다.
* 모바일 브라우저에서는 화면 전체를 자연스럽게 사용한다.
* 전체 배경은 밝고 깔끔하게 구성한다.
* 앱 화면은 하나의 완성된 모바일 애플리케이션처럼 보이게 만든다.

---

## SPA 화면 구성 기준

이 프로젝트는 SPA 방식으로 구현한다.  
화면은 다음 기준을 만족해야 한다.

* 현재 활성화된 화면만 표시한다.
* 서로 다른 화면이 동시에 표시되지 않도록 한다.
* 화면 전환 시 기존 화면은 사용자에게 보이지 않아야 한다.
* 화면 전환은 별도의 페이지 이동 없이 자연스럽게 이루어진다.
* 모든 화면은 독립적인 화면처럼 보이도록 구성한다.

---

## 전체 디자인 분위기

전체적으로 다음 느낌을 유지한다.

* 밝고 깔끔한 화면
* 충분한 여백
* 둥근 모서리
* 읽기 쉬운 글자
* 부담스럽지 않은 색상
* 고객센터 서비스에 어울리는 안정적인 분위기

---

## 색상 방향

정확한 색상 코드를 강제하지 않는다.

다음 색상 느낌을 유지한다.

* 메인 색상: 파란색 계열
* 전체 배경: 연한 회색 또는 연한 파란 회색
* 카드 및 패널 배경: 흰색
* 기본 글자: 진한 회색 또는 검정 계열
* 보조 글자: 회색 계열
* 사용자 메시지: 파란색 계열
* 챗봇 메시지: 흰색 또는 밝은 회색 계열
* 오류 메시지: 붉은색 계열

---

## 공통 UI 기준

* 화면 요소 사이에는 충분한 간격을 둔다.
* 입력창, 버튼, 말풍선은 둥근 형태를 사용한다.
* 버튼과 입력창은 모바일에서 누르기 편한 크기로 만든다.
* 글자 크기는 너무 작지 않게 한다.
* 화면 전체가 답답하지 않게 보이도록 구성한다.

---

## 로그인 화면

로그인 화면은 화면 중앙에 정돈된 로그인 폼이 배치된 형태로 만든다.

포함 요소는 다음과 같다.

* 화면 제목
* 사용자 이름 입력 필드
* 패스워드 입력 필드
* 로그인 버튼
* 오류 메시지 영역

디자인 기준은 다음과 같다.

* 제목은 화면에서 가장 눈에 띄도록 표시한다.
* 입력 필드는 충분한 너비와 높이를 가진다.
* 로그인 버튼은 입력 필드 아래에 배치한다.
* 로그인 버튼은 주요 액션 버튼으로 강조한다.
* 오류 메시지는 사용자가 쉽게 인식할 수 있어야 한다.
* 전체적으로 단순하지만 허전하지 않게 구성한다.

---

## 채팅 화면

채팅 화면은 실제 메신저 앱처럼 구성한다.

화면은 다음 세 영역으로 구성한다.

```text
상단 헤더 영역
채팅 메시지 영역
하단 메시지 입력 영역
```

디자인 기준은 다음과 같다.

* 헤더는 화면 상단에 항상 보인다.
* 메시지 입력 영역은 화면 하단에 항상 보인다.
* 채팅 메시지 영역은 화면의 나머지 공간을 사용한다.
* 메시지가 많아질 경우 채팅 메시지 영역만 스크롤된다.
* 전체 화면이 함께 스크롤되지 않도록 구성한다.

---

## 헤더 영역

헤더에는 다음 요소를 배치한다.

* 서비스 제목
* 로그아웃 버튼

디자인 기준은 다음과 같다.

* 서비스 제목은 왼쪽에 배치한다.
* 로그아웃 버튼은 오른쪽에 배치한다.
* 헤더는 채팅 화면의 상단 영역으로 명확하게 구분되게 만든다.
* 깔끔하고 안정적인 느낌을 유지한다.

---

## 채팅 메시지 영역

채팅 메시지 영역에는 챗봇과 사용자의 대화 내용을 표시한다.

디자인 기준은 다음과 같다.

* 챗봇 메시지는 왼쪽에 표시한다.
* 사용자 메시지는 오른쪽에 표시한다.
* 챗봇과 사용자의 말풍선 색상은 서로 다르게 만든다.
* 말풍선은 둥근 형태로 만든다.
* 메시지 사이에는 적당한 간격을 둔다.
* 긴 문장도 읽기 편하게 줄바꿈되도록 한다.

---

## 챗봇 메시지

* 밝은 색 말풍선을 사용한다.
* 차분하고 안정적인 느낌을 준다.
* 여러 줄 답변도 읽기 편해야 한다.

---

## 사용자 메시지

* 파란색 계열 말풍선을 사용한다.
* 챗봇 메시지와 명확히 구분되게 만든다.
* 글자는 충분히 잘 보여야 한다.

---

## 메시지 입력 영역

포함 요소는 다음과 같다.

* 메시지 입력 필드
* 전송 버튼

디자인 기준은 다음과 같다.

* 입력 필드는 충분히 넓게 만든다.
* 전송 버튼은 입력 필드 오른쪽에 배치한다.
* 입력 필드와 버튼은 같은 줄에 자연스럽게 정렬한다.
* 사용자가 바로 입력할 수 있도록 눈에 잘 띄게 만든다.

---

## 응답 처리 중 상태

챗봇 응답을 기다리는 동안 사용자가 현재 처리 중임을 알 수 있어야 한다.

다음과 같은 표현을 사용할 수 있다.

* 전송 버튼 상태 변경
* 스트리밍 응답 표시

전체 경험은 자연스럽고 끊김 없이 보이도록 한다.

---

## 버튼과 입력창

* 버튼은 누를 수 있다는 느낌이 명확해야 한다.
* 마우스를 올리면 가볍게 강조한다.
* 클릭 시 반응이 느껴져야 한다.
* 입력창은 현재 입력 중임을 쉽게 알 수 있어야 한다.
* 비활성화 상태는 명확하게 구분한다.

---

## 접근성

다음 기준을 지킨다.

* 사용자 이름 입력창에는 label을 제공한다.
* 패스워드 입력창에는 label을 제공한다.
* 버튼은 키보드로 접근 가능해야 한다.
* 글자 크기는 너무 작지 않게 한다.
* 배경색과 글자색은 충분히 구분되게 한다.

---

## 최종 디자인 목표

구현 결과는 다음과 같은 느낌을 제공해야 한다.

* 모바일 앱처럼 보인다.
* 실제 고객센터 서비스처럼 보인다.
* 로그인 화면은 단순하고 깔끔하다.
* 채팅 화면은 메신저 앱처럼 자연스럽다.
* 로그인 화면과 채팅 화면은 동시에 보이지 않는다.
* 전체 UI가 완성도 있고 신뢰감 있게 보인다.
