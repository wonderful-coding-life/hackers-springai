# 1. PRD (Product Requirements Document)

PRD는 기능 요구사항 문서입니다.

여기서는 UI 디자인 이야기를 하지 않습니다.

대신
```
무엇을 만들어야 하는가?
무엇을 할 수 있어야 하는가?
```
를 작성합니다.

예시
```
로그인 기능 제공

사용자는 사용자명과 비밀번호로 로그인할 수 있다.

채팅 기능 제공

사용자는 질문을 입력할 수 있다.
AI는 답변을 생성한다.

로그아웃 기능 제공
```
PRD는 기능 설명에 집중합니다.

# 2. Wireframe

Wireframe은 화면 배치 문서입니다.

여기서는 색상이나 디자인 이야기를 하지 않습니다.

대신
```
무엇이 어디에 있는가?
```
를 작성합니다.

예시
```
┌───────────────┐
│ 고객센터       │
├───────────────┤
│ 메시지 목록    │
│               │
├───────────────┤
│ 입력창 전송    │
└───────────────┘
```
또는
```
헤더
채팅영역
입력영역

챗봇 메시지 → 왼쪽
사용자 메시지 → 오른쪽
```
Wireframe은 구조 설명에 집중합니다.

# 3. Design

Design 문서는 디자인 방향 문서입니다.

여기서는 위치나 기능 설명을 하지 않습니다.

대신
```
어떤 느낌이어야 하는가?
```
를 작성합니다.

예시
```
ChatGPT 앱 느낌

깔끔하고 신뢰감 있는 스타일

충분한 여백 사용

파란색 계열 중심

친근한 고객센터 분위기

모바일 앱처럼 보이는 화면
```
Design 문서는 분위기 설명에 집중합니다.
