# 채팅 화면 와이어프레임

## 화면 개요

캠퍼스 고객센터 AI 챗봇과 대화하는 채팅 화면이다.

모바일 앱 형태의 단일 화면으로 구성한다.

---

## 화면 구조

```text
┌──────────────────────────────┐
│ 캠퍼스 고객센터      로그아웃 │
├──────────────────────────────┤
│                              │
│ ┌────────────────────┐       │
│ │ 안녕하세요.         │       │
│ │ 무엇을 도와드릴까요?│       │
│ └────────────────────┘       │
│                              │
│       ┌────────────────────┐ │
│       │ 수강신청 기간이    │ │
│       │ 언제인가요?        │ │
│       └────────────────────┘ │
│                              │
│ ┌────────────────────┐       │
│ │ 수강신청 기간은    │       │
│ │ 다음과 같습니다.   │       │
│ └────────────────────┘       │
│                              │
├──────────────────────────────┤
│ ┌────────────────────┐ ┌───┐ │
│ │ 메시지 입력        │ │전송│ │
│ └────────────────────┘ └───┘ │
└──────────────────────────────┘
```

---

## UI 구성 요소

### 1. 헤더 영역

```text
캠퍼스 고객센터
로그아웃
```

### 2. 채팅 영역

채팅 메시지를 표시하는 영역이다.

#### 챗봇 메시지

```text
좌측 말풍선
```

#### 사용자 메시지

```text
우측 말풍선
```

### 3. 메시지 입력 영역

```text
메시지 입력 필드
전송 버튼
```
