

# Spring AI MCP Client

## npx 기반의 MCP Server를 연결
노션 MCP Server
노션에 토큰을 획득하면 해당 페이지에 접근

## 파일 시스템 MCP Server
파일 시스템에서 파일을 읽고 쓰는 기능.
주로 텍스트 기반의 파일 *.txt, *.md에 적합

## 서버 패치 MCP Server - 웹 페이지 가져오는 기능
LLM은 인터넷 검색을 하지 않아 최신 정보를 가져오기 위해서는 웹 검색을 해야 함.
Brave Search와 같인 검색 서버와 웹 페이지 패치 서버를 둘 다 사용하는 것이 일반적이나
ChatGPT도 기본적인 웹 검색 서버 역할은 함. 날씨, 증권 각각 어디에서 검색하면 되는지 기본 정보는 알고 있음.

## 전세계 날씨
Open-Meteo MCP Server는 STDIO 방식을 지원하고 무료로도 대부분의 정보를 얻을 수 있다. 유료라면 API Key를 사용하여 응답 속도 개선 및 기타 상업적인 목적으로 사용할 수 있다.
```properties
spring.ai.mcp.client.stdio.connections.weather.command=npx
spring.ai.mcp.client.stdio.connections.weather.args=-y,open-meteo-mcp-server
```
```shell
npx @modelcontextprotocol/inspector npx -y open-meteo-mcp-server
```

## 메시지 예
내일 서울 날씨랑 날씨에 따른 의상 코디 추천해줘.
```txt
내일(2026-05-30) 서울 날씨 요약과 의상 코디 추천입니다.

요약
- 날씨: 흐림(구름 많음, weathercode 3)
- 강수: 예상 강수량 0 mm → 비는 거의 없음
- 기온: 최저 13.5°C / 최고 27.5°C
- 특징: 일교차 큼 — 아침·저녁은 쌀쌀하고 낮에는 덥고 습하지 않은 편

의상 코디 추천 (레이어링이 핵심)
- 기본 원칙
  - 아침/저녁(약 13~16°C): 가벼운 겉옷 필요(얇은 니트, 가디건, 얇은 점퍼 등).
  - 낮(약 25~28°C): 반팔·얇은 소재로 시원하게, 필요하면 겉옷은 휴대.
  - 비가 없으니 우산은 필수는 아님(선호 시 소형 우산 한 개만).

- 출근/오피스
  - 남성: 반팔 폴로셔츠 또는 얇은 셔츠 + 얇은 니트나 가벼운 블레이저. 하의는 슬랙스(통기성 좋은 소재).
  - 여성: 블라우스(반팔 또는 7부) + 가디건/얇은 재킷. 스커트나 가벼운 슬랙스 추천.
  - 신발: 로퍼/플랫/단정한 스니커즈. 아침엔 양말+신발이 주는 온기 고려.

- 캐주얼(주말·외출)
  - 남성: 반팔 티셔츠 + 얇은 셔츠(오픈) 또는 얇은 바람막이(접어 다니기 좋음). 반바지 또는 청바지.
  - 여성: 반팔 티+가벼운 가디건, 롱 셔츠 원피스 위에 얇은 재킷. 활동적이면 반바지+스니커즈.
  - 액세서리: 선글라스, 휴대 가능한 얇은 가디건 혹은 숄.

- 야간 외출/데이트
  - 얇은 가죽 재킷 또는 트렌치(무겁지 않은 버전). 실내는 더울 수 있으니 레이어 벗기기 편하게.
  - 컬러: 흐린 날엔 밝은 컬러(화이트, 라이트 블루, 파스텔)로 얼굴 환하게 연출.

- 운동/야외 활동
  - 통기성 좋은 반팔 티 + 가벼운 트레이닝 재킷(아침 스트레칭용). 낮에는 재킷 벗고 운동.
  - 신발: 통풍 잘되는 러닝화.

- 특별 팁
  - 아침 체감 온도는 최저 근처라 가디건이나 경량 패딩(초여름용 얇은 타입) 한 겹 준비.
  - 낮에는 자외선이 낮지 않을 수 있으니 선크림(필요 시) + 선글라스.
  - 흐린 날이므로 밝은 색 옷을 입으면 얼굴이 더 환해 보입니다.
  - 가방에 얇은 겉옷을 접어 넣어 이동 중 체온 조절하세요.

원하시면 시간대별(아침·낮·저녁) 추천 코디 사진 예시나 쇼핑 링크로 구체 제안도 해드릴게요. 어떤 스타일(포멀/캐주얼/스포티 등)을 더 원하시나요?
```
내 컴퓨터에 있는 meeting-minutes.txt 파일을 요약해서 회의요약 페이지 작성해 줘.
