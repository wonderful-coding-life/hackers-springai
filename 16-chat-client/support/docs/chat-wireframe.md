# 채팅 화면 와이어프레임

## 화면 개요

캠퍼스 고객센터 AI 챗봇과 대화하는 채팅 화면이다.

모바일 앱 화면처럼 세로로 긴 단일 화면으로 구성한다.

---

## 화면 구조

```text
┌──────────────────────────────┐
│ 캠퍼스 고객센터   user1 로그아웃 │
├──────────────────────────────┤
│                              │
│ ┌────────────────────┐       │
│ │ 안녕하세요.         │       │
│ │ 무엇을 도와드릴까요?│       │
│ └────────────────────┘       │
│ 챗봇                         │
│                              │
│       ┌────────────────────┐ │
│       │ 수강신청 기간이    │ │
│       │ 언제인가요?        │ │
│       └────────────────────┘ │
│                         나   │
│                              │
│ ┌────────────────────┐       │
│ │ 수강신청 기간은    │       │
│ │ 다음과 같습니다.   │       │
│ └────────────────────┘       │
│ 챗봇                         │
│                              │
│       ┌────────────────────┐ │
│       │ 감사합니다.        │ │
│       └────────────────────┘ │
│                         나   │
│                              │
├──────────────────────────────┤
│ ┌────────────────────┐ ┌───┐ │
│ │ 채팅 문장 입력     │ │전송│ │
│ └────────────────────┘ └───┘ │
└──────────────────────────────┘
```

---

## UI 구성 요소

### 1. 헤더 영역

```text
캠퍼스 고객센터   로그인사용자이름   로그아웃
```

헤더에는 다음 정보를 표시한다.

* 서비스 제목: `캠퍼스 고객센터`
* 로그인 사용자 이름
* 로그아웃 버튼

### 2. 채팅 영역

챗봇과 사용자의 대화 메시지를 표시한다.

#### 챗봇 메시지

```text
좌측 말풍선
```

* 챗봇이 답변한 메시지는 왼쪽에 표시한다.
* 말풍선 아래 또는 옆에 `챗봇` 표시를 둘 수 있다.

#### 사용자 메시지

```text
우측 말풍선
```

* 사용자가 입력한 질문은 오른쪽에 표시한다.
* 말풍선 아래 또는 옆에 `나` 표시를 둘 수 있다.

### 3. 메시지 입력 영역

화면 하단에 고정한다.

```text
채팅 문장 입력 + 전송 버튼
```

구성 요소:

* 채팅 문장 입력 필드, 스크롤바 비노출
* 전송 버튼

---

## 화면 동작

1. 사용자가 하단 입력창에 메시지를 입력한다.
2. 전송 버튼을 클릭한다.
3. 사용자 메시지가 우측 말풍선으로 추가된다.
4. 서버에 채팅 API 요청을 보낸다.
5. 챗봇 응답은 좌측 말풍선으로 표시된다.
6. 스트리밍 응답을 받는 경우, 챗봇 말풍선에 텍스트를 이어 붙인다.
7. 로그아웃 버튼을 클릭하면 인증 정보를 삭제하고 로그인 화면으로 이동한다.

---

## 디자인 가이드

* 모바일 앱처럼 세로로 긴 화면을 기준으로 설계한다.
* 헤더는 화면 상단에 고정한다.
* 메시지 입력 영역은 화면 하단에 고정한다.
* 채팅 영역은 헤더와 입력 영역 사이에서 스크롤 가능하게 구성한다.
* 챗봇 말풍선은 좌측 정렬한다.
* 사용자 말풍선은 우측 정렬한다.
* 챗봇과 사용자의 말풍선 색상은 서로 구분되도록 한다.
